# ChatLuna Impart

ChatLuna V2 群聊数值游戏。支持打胶（长度）、挖矿（深度）、玩家排行与分群银趴开关，排行榜图片由 Takumi 离线渲染。

## 指令

指令是否需要 `/` 或 @机器人，以宿主的命令前缀设置为准。

| 指令 | 功能 |
| --- | --- |
| `银趴` / `impart` | 指令说明 |
| `打胶 [@成员]` / `开导 [@成员]` | 成功增加长度，失败减少长度 |
| `挖矿 [@成员]` | 成功增加深度，失败深度回升 |
| `看看牛牛 [@成员]` | 查看长度、深度与生长系数 |
| `牛牛排行榜` | 长度从大到小排列 |
| `挖矿排行榜` / `深度排行榜` | 深度从深到浅排列 |
| `开始银趴` | 开放当前群的游戏功能 |
| `结束银趴` | 暂停当前群的游戏功能 |

也可使用完整命令名：`impart.train`、`impart.mine`、`impart.profile`、`impart.rank`、`impart.mining-rank`、`impart.start`、`impart.end`。

- 仅支持群聊。无参数时操作自己；帮助他人时使用同平台、本群成员的提及，不接受全体成员或跨平台目标。
- 长度与深度是两个独立数值：打胶只改变长度，挖矿只改变深度。首次打胶只初始化长度，首次挖矿只初始化深度，不执行数值变化；已有长度的玩家首次挖矿时仍需先初始化深度。帮助他人时先初始化目标，再初始化发起者，分次完成。
- 初始长度默认在 `0 ~ 18 cm` 之间随机，初始深度默认在 `-18 ~ 0 cm` 之间随机，两者的上下限都可在配置中修改；生长系数在首次参与时随机取 `[0, 1)`，长度与深度共用。
- 成功变化为 `10 ±45% cm × (1 + 生长系数)`；失败反向变化为 `12 ±45% cm`，不乘系数。
- 打胶成功长度增加、失败减少；挖矿成功深度数值减小（挖得更深）、失败回升。打胶按当前长度匹配成功率，挖矿按当前深度的相反数匹配。数值越大，继续向该方向发展的成功率越低。
- 长度与深度都允许跨过零点，保存与显示精度为 `0.01 cm`。牛牛排行榜只列已初始化长度的玩家，挖矿排行榜只列已初始化深度的玩家，按有符号深度升序排列。
- 默认冷却 5 秒。打胶和挖矿共用冷却，同平台跨群共享；帮助他人时双方都检查并消耗冷却。初始化及有效操作的成功、失败均计入冷却。

## 群开关与权限

新群默认开放，可在配置中改为默认关闭。开始和结束是明确设置，不是反转：重复开始仍为开放，重复结束仍为暂停。

暂停后，本群打胶、挖矿、查询和排行榜均停止响应业务操作；已有长度、深度、冷却和排行榜数据保留。

开关指令需要宿主权限等级 3。群身份映射由 ChatLuna 的平台权限插件处理，通常为群主或管理员；是否要求机器人也具有群管理员身份，以宿主权限配置为准。

## 仪表盘统计

启用 WebUI 时，插件在 ChatLuna 仪表盘添加「银趴」卡片，显示玩家数、进行中与全部群数，并按参与人数列出前 6 个群，每个群按长度列出最长与最短各 5 名（中间名次省略）及开关状态。卡片使用宿主 ui-kit，支持中文和英文。配置项「仪表盘统计」默认开启，关闭后不注册卡片。群开关只通过聊天指令操作。

数值规则、冷却、默认群状态、图片模式、排行榜人数和范围在宿主插件配置中管理。排行榜默认前 15 人，最多 50 人；群榜统计历史参与者，不是实时群成员名册。跨群榜仅包含当前平台玩家。

图片使用内置 Noto Sans SC 中文字体，不需要浏览器或远程字体服务。渲染失败时明确提示并回退文字，不影响游戏数据。

## 安装要求

- ChatLuna V2、Node.js 24 或更新版本。
- 宿主提供数据库、Koishi 平台命令桥与权限服务。命令无需配置模型，也不调用 AI。
- WebUI 为可选能力；未启用 WebUI 时游戏指令仍可使用。
- 数据保存在插件独立表中，重新加载插件不会清空玩家和群开关；不自动转换 Koishi 旧插件数据库。
