# tests 说明

适用范围：`tests/`。同时遵守根 `AGENTS.md`；业务见 `src/AGENTS.md`。

- 使用独立的真实内存 SQLite 数据库测试事务、持久化和隔离；只替换随机数、时间等外部边界，不重写业务算法作为断言。
- 覆盖冷却并发、长度与深度及其系数分别初始化及互不影响、按玩法分开的群参与记录与旧数据迁移、负长度与深度、失败、群开关、权限、目标解析和渲染失败的文本回退。
- 设置页表格在 jsdom 中挂载真实 SchemaForm，覆盖列头、编辑、排序、删除到空数组、新增默认值、无效区间提示，以及扩展与仪表盘卡片随客户端生命周期注册和注销。
- Takumi 测试真正生成 PNG，检查文件签名与尺寸；不依赖外网字体、头像或浏览器截图。
- 本地验证与 `scripts/publish.mjs` 都用 `yarn test`，即插件声明的 vitest，不直接调用宿主根目录的 vitest（大版本可能不同）。客户端语言 `.yml` 由 `vitest.config.ts` 的转换插件替换为空模块，不用 `vi.mock`（vitest 4 仍会把原文件当 JS 解析），升级 vitest 后也能通过。
- 测试结束释放上下文、数据库与自建进程；onebot-sandbox 只用隔离空间，不清理用户真实数据。
- 守卫测试核对全部子目录 AGENTS 已登记、登记路径存在及已移除功能不再注册。
